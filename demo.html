🚀 Installation Instructions

Step 1: Download the Extension

Clone or download the repository from GitHub:

git clone https://github.com/hahahah12345678/any-model.git

Step 2: Enable Developer Mode

In Chrome, navigate to chrome://extensions/ and toggle "Developer mode" on.

Step 3: Load the Extension

Click "Load unpacked" and select the any-model directory.

Step 4: Start Creating!

Click the AnyModel icon in your Chrome toolbar to open the 3D modeling studio.
